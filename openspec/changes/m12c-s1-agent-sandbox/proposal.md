## Why

The historical smoke failed its methodological gate because unrestricted host
shell access allowed context contamination. A new comparison needs a tested,
shared execution boundary and a complete environment identity before dispatch.

## What Changes

- Specify a draft scientific protocol for shared sandbox conditions while retaining three distinct architecture semantics.
- Require offline effective-policy acceptance evidence before freezing an environment identity.
- Quarantine historical results and require renewed registration and explicit live authorization.
- Define future acceptance scenarios; this documentation change does not implement a sandbox or authorize paid calls.

## Capabilities

### New Capabilities

- `sandbox-comparison-protocol`: Environment identity, acceptance gates and evidence rules for sandboxed architecture comparisons.

### Modified Capabilities

None.

## Impact

Adds `docs/m1.2c-s1-scientific-protocol.md` and an OpenSpec protocol specification.
Future runtime, integration, benchmark and store implementations need coordinated
work under `CONTRACTS.md`. No production APIs, dependencies or historical records
change in this proposal.
