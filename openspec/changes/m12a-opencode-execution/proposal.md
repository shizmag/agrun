# Offline-verified OpenCode execution foundation

## Why
Scientific comparisons need auditable agent execution, request accounting, and
honest resource enforcement independently of benchmark quality. The existing
experimental CLI adapter does not establish those contracts.

## What Changes
- Audit the installed CLI protocol and preserve normalized and raw event evidence.
- Freeze model profiles; deduplicate request usage and version cost estimates.
- Add shared local admission with explicit enforcement capabilities and offline
  fixture authorization. Reject unsupported required hard budgets before launch.
- Preserve partial histories and process outcomes through immutable existing store
  artifacts, and expose reconstructable scientific execution summaries.
- Verify deterministic executable fixtures, lifecycle races and independent
  benchmark integration without provider calls.

## Impact
Enhance the CLI adapter; retain runtime, SQLite store, DSL and independent grader.
No provider gateway, network-isolation claim, paid execution, deployment or merge.
