# M1.2c-S3: release calibration and environment freeze

## Why

S2 restored quiescent export and offline comparative execution, but plugin and
LSP negatives lack valid enabled controls. Silence alone is not release evidence.

## Scope

Calibrate the exact installed binary using local paired fixtures, independently
audit the existing sandbox, and freeze its complete experimental identity only
after mandatory gates pass. No runtime redesign or paid provider calls.

## Acceptance

Valid enabled/disabled and inheritance controls, installed security regression,
adversarial mutations, clean post-commit three-architecture acceptance, independent
audited-v2 regrades, and content-addressed unchanged-runtime validation are required.
Preserve historical observations. Report PARTIAL rather than invent a freeze.
