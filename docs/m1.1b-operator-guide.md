# M1.1b controlled execution

These commands do not enable authoritative scoring. `--diagnostics` executes
the selected official tests but persists an **untrusted diagnostic**, with nil
quality score. It is not interchangeable with either named scoring protocol.
No live providers are registered.

## Inspect and prepare

```sh
mise exec -- bundle exec ruby bin/agru bench verify nl2repo --offline
mise exec -- bundle exec ruby bin/agru bench tasks nl2repo --offline
mise exec -- bundle exec ruby bin/agru bench prepare nl2repo --task retrying --allow-download --allow-local-specification-use
```

`verify` intentionally exits nonzero while authoritative grading is unavailable.
Preparation downloads only with explicit authorization; subsequent offline runs
do not pull images. Local specification consent does not grant redistribution
rights. The image is selected by an approved digest, not the mutable tag alone.

Inspect `benchmarks/nl2repo/protocols.json`,
`benchmarks/nl2repo/selected-task-controls.json`, and
`docs/m1.1b-grader-compatibility.md` for protocol and asset identities.

## Deterministic repository submission and existing runner

Create a local directory containing only the intended implementation, not private
tests or a reference implementation. The explicit importer checks filesystem
boundaries, **not semantic provenance**. Do not use a grading-only reference as
solver-visible input or represent it as generated code.

```sh
mise exec -- bundle exec ruby bin/agru bench plan experiments/nl2repo-official-smoke.json --offline
mise exec -- bundle exec ruby bin/agru bench run experiments/nl2repo-official-smoke.json --offline --repository PATH_TO_CONTROL --diagnostics
mise exec -- bundle exec ruby bin/agru bench report nl2repo-official-smoke --format json
mise exec -- bundle exec ruby bin/agru bench report nl2repo-official-smoke --format csv
mise exec -- bundle exec ruby bin/agru bench report nl2repo-official-smoke --format markdown
mise exec -- bundle exec ruby bin/agru bench regrade nl2repo-official-smoke de5c933a0ba1f7a757f24b6d76f37d70342d049e65e8f07c3e155a32852fcb9d --offline --diagnostics
```

Regrade retrieves the captured immutable submission, not the current local
directory, and does not run a solver. Experiment IDs are insert-only: use a new
ID in a copied manifest for another control; do not delete earlier evidence to
reuse an ID. `.agru` contains private execution state and must not be committed.

## Historical parser probe and image-only controls

```sh
python3 script/m11b_legacy_parser_probe.py
mise exec -- bundle exec ruby script/m11b_retrying_original_reference.rb --allow-download
mise exec -- bundle exec ruby script/m11b_retrying_diagnostics.rb --allow-local-diagnostics
```

The first command executes only the checksum-verified parser AST, not the full
legacy grader. Reference acquisition uses a genuine Apache-2.0 upstream commit
and retains source provenance privately; do not export it to a solver workspace.
The final command reproduces grading-only diagnostic controls and keeps
official test contents inside the image. It is not exact legacy replay: clean
candidate directories and offline prefix installation are explicit deviations.
See `docs/m1.1b-isolation.md` for concrete platform and authority limitations.
