# M1.1b test and evidence matrix

This milestone distinguishes offline contract regressions, controlled native
diagnostics, and authenticated authoritative evaluation. Passing the first does
not imply either of the latter.

## Initial red/green checkpoint

`test/benchmark/nl2repo_grader_test.rb` initially produced 5 runs,
26 assertions, **one failure**: `missing audited NL2Repo task-specific grader;
generic container execution is not official grading`. This is missing
functionality, not proof of a native scoring defect. Four existing safety
checks passed. The initial independent adversarial additions passed 3 runs /
26 assertions: those are regression tests, not newly demonstrated red tests.

## Acceptance evidence classes

| Scenarios | Required independent oracle |
| --- | --- |
| GR-01–04 | Actual official task tests, verified reference/negative implementations, observed collection/outcomes |
| GR-05 | Forged stdout/structured result cannot authenticate quality |
| GR-06–07 | Protected collection and omitted reference source checked in real preparation boundary |
| GR-08 | Infrastructure errors remain distinct from solution-quality outcomes |
| GR-09 | Distinct procedure identities, with unavailable native compatibility retained |
| GR-10 | Actual consumed submission/task/tests/image/procedure/policy identities |
| GR-11 | New grading attempt of the same stored snapshot, no solver invocation |
| GR-12 | Generic registry/store/runner and reconstructible report, not a side script |

The full 14-mutation ledger and its exercised/unexercised distinctions are in
`docs/m1.1b-adversarial-review.md`. Final command results and real execution
status belong in `docs/m1.1b-verification.md`.

failures and one error: the reviewer root-symlink test constructed the rejecting
solver outside its `assert_raises` while that test was being edited. The final
test places construction inside the assertion; isolated rerun passed 4 runs /
