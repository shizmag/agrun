## Declared threat-model requirements

Agent code, shell descendants, detached children, generated files and completion
messages are untrusted. Trusted supervision/export must remain outside their
modification authority. The Docker daemon, Linux kernel, trusted image/helper,
host controller and validated input provisioning are trusted. This milestone does
not claim resistance to kernel/container-runtime exploits or universal security.

The agent must not acquire trusted supervisor credentials/capabilities, modify
its code/control channel, or impersonate trusted quiescence evidence. All
untrusted writers must be terminated and reaped before the first export read.
No host fallback, arbitrary network access, grader/reference mounts, host home,
Docker socket or provider credential is permitted. Hard workspace quota must not
silently become a best-effort output check.

## Independent mutation review (focused tests)

Mutations were applied to disposable copies, never production files. The archive
metadata suite rejected a missing second terminator and caught forced file mode
0644 and directory mode 0755. The deadline helper suite caught replacing the
remaining shared budget with the original timeout; this does not independently
prove integrated lifecycle phases share the same instance. A supervisor kill
omission was caught by the Docker readiness timeout.

A blocked-sandbox host fallback mutation initially **survived** the adapter suite
(3 runs, 20 assertions, no failures): it only covered successful sandbox calls.
After adding a blocked-result host execution spy, the unmodified suite passed
(4 runs, 26 assertions) and the identical mutant was **killed** by the explicit
`blocked sandbox must not invoke host execution` assertion (expected 0 calls,
actual 1; 4 runs, 21 assertions, one failure). This establishes coverage of
that fallback branch, not every possible host execution path.

The post-update supervisor-only real Docker suite independently passed 7 runs,
78 assertions, no failures/errors/skips. This is not the integrated runner gate.

Interim regression ledger: `.agru/m12cs2-interim-regression.log` recorded 871
runs, 5,344 assertions, one failure and 53 skips. The sole failure was the S1
cancellation oracle expecting `workspace copy cancelled`; cancellation now
occurs earlier at supervisor snapshot. The updated test asserts the cancelled
status, exact new phase, and zero Docker calls. Subsequent offline boundary run
passed 16 runs, 47 assertions, with 8 expected Docker opt-in skips.
