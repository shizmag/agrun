# M1.2a offline operator guide

## Safety and interpretation

No provider-capable sessions are authorized by this milestone. Environment
credentials and `live: true` are not grants. Only audited absolute executable
fixture paths with pinned SHA256 are admitted. Credentials are removed from
fixture environments and redacted from evidence. These checks are **not network
isolation**, nor do they defend trusted fixture directories against hostile
check-to-spawn replacement. Do not supply production credentials.

Installed CLI readiness may be inspected without starting a session:

```sh
opencode --version
opencode run --help
shasum -a 256 "$(command -v opencode)"
```

The audited version is v2.3.0, binary SHA256
`9f3147cae4ca323827d3ca39451b0d3431b2906e79a08e9b09d1eb34bb703f52`.
An exact upstream revision could not be established. Never substitute the
adjacent SDK package version. A changed CLI requires another protocol audit.

## Offline demonstration

The simulator itself is an ordinary local Ruby script, not an OpenCode session:

```sh
M12_SCENARIO=duplicate mise exec -- ruby test/fixtures/m12_fake_opencode.rb run --format json --standalone -- synthetic
mise exec -- bundle exec ruby -Itest test/m12_adapter_execution_test.rb
mise exec -- bundle exec ruby -Itest test/m12_budget_launch_test.rb
mise exec -- bundle exec ruby -Itest test/m12_scenario_acceptance_test.rb
```

The tests demonstrate actual process launch, immutable evidence, usage,
admission and process cleanup. Scenario names are in the executable fixture;
none invokes a provider. All raw-event debugging must treat artifacts as
sensitive even after redaction (no universal secret detector exists).

Run a persisted multiarchitecture fixture experiment:

```sh
mise run m12-acceptance
mise exec -- bundle exec ruby script/m12_execution_acceptance.rb --root .agru/m12-acceptance --inspect --report json
mise exec -- bundle exec ruby script/m12_execution_acceptance.rb --root .agru/m12-acceptance --inspect --report csv
mise exec -- bundle exec ruby script/m12_execution_acceptance.rb --root .agru/m12-acceptance --inspect --report markdown
mise run m12-test
mise run m12-mutations
```

`--inspect` reopens stored artifacts and reconstructs telemetry; it does not
execute solver work. JSON includes execution/usage/budget evidence independently
of quality. CSV and Markdown are compact scientific projections. `.agru` is local
run state and must not be committed. The fixture grader measures fixture tasks,
not an official NL2Repo result.

When the already-pinned local grading image and task assets are installed, the
explicit opt-in command below runs the actual audited-v2 grader on repository
output generated by a registered fake executable. It performs no model request:

```sh
mise run m12-audited-acceptance
```

For event-level inspection, usage, budget decisions and reconstruction, this
command selects the first persisted fixture cell and reopens its immutable log:

```sh
mise exec -- bundle exec ruby -Ilib <<'RUBY'
require "agent_runtime"
require "agent_runtime/execution/summary"
root = ".agru/m12-acceptance"
store = AgentRuntime::Store.new(root)
id = JSON.parse(File.read(File.join(root, "last-experiment.json"))).fetch("experiment_id")
cell = store.report(id).fetch("cells").first
run_id = cell.fetch("execution").fetch("run_id")
attempt = store.report(run_id).fetch("steps").values.first.fetch("attempts").first
trace = JSON.parse(store.value(attempt.fetch("log"))).fetch("execution")
puts JSON.pretty_generate(trace.slice("events", "admission", "usage"))
puts trace.dig("process", "stdout") # authoritative JSONL in fixture records
puts JSON.pretty_generate(AgentRuntime::Execution::Summary.from_run(store: store, run_id: run_id))
RUBY
```

The corresponding Store API is:

```ruby
require_relative "lib/agent_runtime"
require_relative "lib/agent_runtime/execution/summary"
store = AgentRuntime::Store.new(".agru/m12-acceptance")
report = store.report(run_id) # obtain run_id from the experiment cell execution
attempt = report.fetch("steps").values.first.fetch("attempts").first
trace = JSON.parse(store.value(attempt.fetch("log"))).fetch("execution")
puts JSON.pretty_generate(trace.fetch("events"))
puts JSON.pretty_generate(trace.fetch("admission"))
puts JSON.pretty_generate(AgentRuntime::Execution::Summary.from_run(store: store, run_id: run_id))
```

Root-step counters are observations, not proven unique provider request counts.
The audited CLI does not establish descendant billing coverage or a native
session-terminal event. Unknown counters/cost remain unknown. Native CLI cost
may be calculated by OpenCode and cannot be labeled a provider charge. Estimates
require a versioned, pinned profile matching **observed** provider/model; native
events do not ordinarily establish that identity.

## Limits and remaining live work

Attempt counts and concurrent local sessions are enforced by a shared in-process
coordinator. Run/experiment/pool quotas apply only when hosts inject shared
scopes; per-adapter defaults are run-local. State is not a durable distributed
quota and does not survive host crashes. Wall deadlines supervise local process
groups with bounded cleanup grace; they cannot stop already-accepted remote work.
Token, provider request, monetary and tool hard limits are unsupported by this
CLI transport and required guarantees reject preflight. Monitoring delayed events
cannot guarantee zero overshoot. No provider gateway is implemented.

Retries require the existing explicit `retry_safe` flag and transport category.
Interrupted side-effecting sessions remain unsafe to replay. Partial files and
patches never imply successful execution or independent test quality.
