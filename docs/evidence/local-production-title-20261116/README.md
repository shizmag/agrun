# Production launch auxiliary-request regression

Offline Docker test uses the installed OpenCode executable and configuration
generated by `SandboxOpenCodeLaunch#environment`, plus the production
`local_token_bridge.cjs`. No live API calls were made.

`red.log` records the genuine failure with title generation enabled: its
auxiliary request has no solver tools. The strict multi-turn offline responder
cannot treat that request as a solver turn. This explains this offline fixture
failure; historical live 403 bodies were not retained, so this does not establish
their exact shape or cause.

The fix disables the auxiliary title agent (`agents.title.disabled: true`). It
does not alter tool security policies, model identity, or the shared cap of 12.
The production solver request exposes V2 `read`, `patch`, and `shell` tools.
No capability metadata change was needed.

`green.log`: `node --test test/local_gateway_docker_test.cjs
test/local_gateway_test.cjs test/local_token_gateway_test.cjs` (9 tests passed).
