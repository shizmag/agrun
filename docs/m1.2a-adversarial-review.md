## Final pass (supersedes prior counts)

Latest full harness run: **34 assertion kills, 2 survivors, 3 error outcomes, 0 unapplied** out of 39. The provider-cost and symlink mutants are killed. Planner omission and reconstructed-request omission are killed by the strict solver parity test. A new offline child trap asserts TERM before KILL; skipping TERM is killed. The unsafe retry mutant is killed by scheduler tests. A new offline failure fixture asserts its partial patch is retained; dropping it is killed. The surviving nil-validation mutant is equivalent because nil is handled in an earlier branch. The configured-provider CLI-argument substitution survives the targeted adapter test: configured provider selection is not directly asserted, although strict solver tests assert observed model remains nil. This is a test gap, not proof of an observed provider.

Error outcomes are not assertion kills: cancellation mutation #21 produced two failures and one error; dropping attempt #25 produced an error when the expected attempt was fetched; denial bypass #27 produced an error in the launch test. These demonstrate the mutated test runs failed, but their exact behavioral assertions need stronger isolation before counting them as assertion kills.
