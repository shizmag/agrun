# M1.2c-S2 results

## A. Status

**PARTIAL — not comparison-eligible and not an accepted environment freeze.**
No paid provider calls were made. No larger pilot is authorized. Historical
Single 14/23, contaminated Fixed timeout/supplemental 13/23, and undispatched DSL
observations remain unchanged. This work extends S1 rather than replacing it.

## B. Writer-quiescent export

A trusted Python PID1 runs outside agent authority. Its only added capabilities
are SETUID, SETGID and KILL; agent processes drop UID/GID, groups and capabilities.
PID1 terminates namespace writers, reaps descendants and checks the process set
before reading the workspace. Agent output cannot spoof the private readiness
channel. The trusted supervisor is snapshotted and hashed before dispatch.
Quota-backed tmpfs remains alive through export; stop/restart loss is tested.

## C. Lifecycle

Preparation, execution, quiescence, archive streaming and verification share one
monotonic deadline. Container removal and private cleanup share a separate,
memoized ten-second emergency budget. Process cleanup has a documented 0.5-second
allowance. Cooperative filesystem checks cannot interrupt an individually blocked
filesystem syscall. Cleanup failure invalidates accepted export and is recorded.

## D. Metadata and immutable evidence

New sandbox manifests bind contents and complete ordinary permission bits,
including directories and root. Unsafe modes, aliases, special objects,
traversal, incomplete archives and resource-limit violations fail closed.
Opt-in Submission mode sidecars preserve modes through immutable capture and
materialization without changing historical Store content digests. The grader's
writable working root is separately normalized; this is not a claim that its
working root retains the immutable submission root's mode.

## E. Installed boundary

Actual native-child host denial has a successful workspace-read control.
Physical-host listener denial has a bridge-network positive control. Injected
redirects are denied without reaching the listener. MCP startup has an enabled
installed positive control and a frozen negative.

**Plugin and LSP startup lack successful per-mechanism positive calibration.**
Their submitted sentinels do not run under frozen settings, but also did not run
in attempted enabled controls. The installed binary preserves those configuration
fields, so they cannot simply be declared unsupported. Caller-supplied extension
configuration is rejected by the mock backend; this launch-contract control does
not close the independent runtime-calibration gap.

## G. Three-architecture parity

The same public retrying specification and an independently authored incomplete
fixture produced three immutable submissions. Each received audited-v2 grading
and independent regrading: all six evaluations collected/executed 23 tests and
passed 3/23. These are infrastructure fixtures, **not model capability results**.
No reference implementation was substituted into a solver workspace.
