# M1.2b scoped live authorization (proposal, tests first)

Status: shared API approved for minimal implementation; production class and
coordinator integration implemented. No provider calls are
authorized by this document or by possession of credentials alone.

## Operator amendment and boundaries

The operator authorizes the OmniRoute exact upstream `cx/gpt-6-luna-low`
retrying live pilot. There are **no numerical token, request, run, or monetary
limits**. Do not replace absent limits with guessed caps. Finite wall time,
local concurrency, explicit opt-in, scoped authorization, expiry, and no fallback
remain mandatory. A local attempt cap is supported when explicitly requested,
but is optional for this pilot. Attempt-scope single-lease accounting remains
an implementation invariant, not an experiment-wide attempt cap.

Local admission is not a provider-side hard financial guarantee. Killing a local
process, expiring authorization, or declining another launch cannot revoke an
already accepted upstream request. Usage and money are observations; unknown
usage remains unknown. Request/run/token/cost hard-bound requests must fail
closed unless an actual enforcement capability is implemented and reviewed.

## Proposed `AgentRuntime::Execution::LiveAuthorization`

New file: `lib/agent_runtime/execution/live_authorization.rb`.

```ruby
LiveAuthorization.new(scope:, expires_at:, financial_exposure:,
  wall_clock: -> { Time.now.to_f })
authorization.preflight!(scope:, hard_limits: {}) # => immutable evidence hash
authorization.to_h                             # => immutable evidence hash
```

`scope` is a string-key Hash with exactly these nonempty String values:
`experiment_digest`, `task`, `solver`, `provider`, `endpoint`, `route`, `model`,
`mode`. Digest is lowercase SHA-256 hex. Scope copies and recursively freezes
caller data; each preflight requires exact equality of every field and rejects
missing/extra fields. Endpoint and route equality is literal (no normalization,
provider alias substitution, or alternate endpoint). Endpoint is the reviewed
non-secret HTTP(S) provider endpoint; credentials/userinfo/query/fragment must
not enter authorization evidence. The experiment digest must cover the frozen
experiment configuration supplied by the runner, not an unrelated digest.

`expires_at` is a finite numeric Unix timestamp; `wall_clock` is injectable for
offline tests. Expiration is checked on every preflight, with `now >= expires_at`
denied. `financial_exposure` must explicitly equal `"not_hard_bounded"`.
Neither missing acknowledgment nor `"hard_bounded"` is accepted. Scope/data
shape, expiry, acknowledgment, mismatch, and any nonempty `hard_limits` cause
`ArgumentError`; adapter/CLI boundaries translate this into blocked execution,
never an evaluation verdict. Rejected preflight must precede process launch.

Evidence is a frozen Hash containing `scope`, `expires_at`, and
`financial_exposure`. It contains no credentials or opaque bearer capability.
Preflight returns this same immutable content; it is not a transferable security
token or a sandbox. The trusted runner owns the authorization instance.

## Existing budget/coordinator integration

`Budget::AdmissionConfig.new(wall_seconds:, max_attempts: nil,
max_concurrent_sessions:, hard_limits: {}, observations: {})` allows absent/null
`max_attempts`, while continuing to require positive finite wall time and a
positive Integer local concurrency bound. Explicit `max_attempts` remains a
positive Integer. `to_h` retains `"max_attempts" => nil` for faithful evidence.

`Budget::Coordinator` remains the sole atomic attempts/concurrency ledger.
Existing finite caps and hard-bound rejection continue unchanged. Coordinator
attempt exhaustion ignores null caps, not wall time or concurrency. No second
counter is introduced in authorization. The adapter/runner reuse one scoped
authorization, call `preflight!` with actual resolved launch identity before
each admission/launch, then use the existing lease and ensure-release path.
They must not fabricate a matching scope from authorization evidence or grant
authorization merely because `model_profile` says `real_provider`.

Coordinator adds `authorization_scope: nil` to its existing `admit` signature.
On real-provider profiles, `authorization:` must be a concrete
`LiveAuthorization` instance, and coordinator calls
`authorization.preflight!(scope: authorization_scope, hard_limits: ...)` before
reservation. A bare Hash, arbitrary callable, or returned evidence Hash cannot
substitute for the authorization instance. On offline profiles, the existing
fixture callback and executable/hash/profile/experiment/run binding are
unchanged. Adapter constructor receives the same concrete instance and actual
launch scope; resolved provider/model/endpoint/route must agree with it.

Parent owns `Benchmarks::LiveExperiment`, manifest/runner/solvers/CLI integration
and evidence nesting; no separate `Live::Preflight` class is proposed. `mode`
may be `"live"`; benchmark retrying/audited procedure identity is additionally
bound by the experiment digest. The exact reviewed values are frozen by the
parent's manifest preflight, not hardcoded generic examples in this contract.

## Offline acceptance tests

`test/m12b_authorization_test.rb` owns immutable/exact scope, expiry,
acknowledgment, unsupported hard bounds, optional local attempts, preserved
explicit attempt caps, finite wall time, and atomic local concurrency. No API,
credential, executable, subprocess, provider, or network is used.

Red baseline against unmodified production implementation:
`mise exec -- bundle exec ruby -Itest test/m12b_authorization_test.rb`
(seed 64004): **12 runs, 22 assertions, 8 failures, 3 errors, 0 skips**.
Eight failures report the missing `LiveAuthorization`; three errors report
`invalid_budget_config: limits must be positive and finite` for null attempt
limits. Existing explicit finite attempt-cap behavior passes. No production
files were changed and no provider calls were made.

Coordinator-boundary denial is represented by its existing negative `Decision`
(not an exception) when a scope mismatch, missing/forged authorization, or expiry
is discovered. Direct `LiveAuthorization#preflight!` calls raise `ArgumentError`.

## Implementation verification

`expires_at` accepts finite numeric Unix epoch seconds only; ISO strings must be
parsed by the parent wrapper before construction. Live grant validation and
expiry recheck execute inside the coordinator mutex, followed by duplicate
attempt, wall time, concurrency, and reservation in that same critical section.
Actual profile provider/model are compared with the granted scope. Admitted
evidence additionally records executable, executable SHA-256, profile digest,
experiment ID, and run ID from the admission call. Parent/D must derive and
validate endpoint/route/manifest/executable identity from actual launch inputs;
this generic coordinator cannot independently inspect a subprocess config.
Adapter instances for the same experiment must share coordinator and scopes;
separate coordinators are independent accounting domains, not a global limit.

New test suite: **12 runs, 114 assertions, 0 failures/errors**. Combined budget,
fixture-launch, and new suite: **33 runs, 241 assertions, 0 failures/errors**.
Parent approved updating the old null-attempt rejection expectation while
preserving invalid wall/concurrency checks. The fixture concurrency regression
now uses two distinct adapter instances sharing coordinator and experiment
scope: exactly one inert process launches under a one-session limit. Concrete
Hash/callback live-grant denial tests are present in the new suite. Targeted
Standard Ruby lint passes. No provider calls or commits were made.
