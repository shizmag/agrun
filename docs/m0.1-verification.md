## Method and responsibilities

Production remains unchanged during contract extraction, independent design,
oracle review, test implementation and initial execution. Initial outcomes are
classified as existing behavior confirmed, implementation defect, ambiguous
contract, defective test, unsupported feature, or infrastructure failure.

| Workstream | Ownership |
|---|---|
| A | DSL/IR contracts and deterministic serialization |
| B | Scheduler, concurrency, retries and process lifecycle |
| C | Artifact provenance and independent evaluation integrity |
| D | Fixture OpenCode adapter, persistence and reports |
| E | Independent adversarial oracle and actual-test review |
| F | Persisted end-to-end acceptance and harness conformance |
| Orchestrator | Contract decisions, integration, fixes, gates and commits |

Each author first records a scenario plan; E challenges expected outcomes before
tests are written and reviews actual assertions before production fixes. Mutation
experiments must be isolated from working production sources.
