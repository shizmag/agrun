# M1.1c offline audited retrying operator guide

This is a **retrying-only infrastructure control**, not an official leaderboard
or paper-compatible result. Protocol `nl2repo-audited-v2` assumes benign ordinary
submissions; candidate-domain structured JSON is not adversarial authentication.
Read `docs/m1.1c-scoring-contract.md` and `docs/m1.1c-collection-contract.md`.

## Prerequisites and paths

Run from the repository root with its installed mise Ruby/bundle and Docker
daemon available. These commands make no downloads, image pulls, or model calls.
The `fixture` model entry is a local manifest label, not a provider invocation.
Do not add `--allow-download`; audited scoring requires `--offline`.

The CLI's default Store is `.agru` (SQLite, immutable artifacts and workspaces).
The dataset root is **Store root plus `/nl2repo`**: default `.agru/nl2repo`.
Changing `--root` therefore also changes where cached dataset/reference assets
must already exist. Ordinary benchmark defaults and the acceptance script's
separate `.agru/m11c-acceptance` output root are not interchangeable.

The cached pinned dataset revision must already be present and the image must
already exist locally:

```sh
docker image inspect ghcr.io/multimodal-art-projection/nl2repobench/retrying@sha256:1302235420db9d34955c42273ebaf23df8bbee31ceeaf3c336347f54b64146fe
```

Missing assets fail closed; do not substitute another image or silently fetch.
The private reference defaults to
`.agru/nl2repo/reference/original-1d5699348d707e377aad7488da6a8a1b48a65933/retrying.py`.
Its module SHA-256 must be
`d8f1cc7e269fe908cae965fb9338d3625c56c9e56a35435dcb6f78ee74a53e0a`.
The current reference check pins that module, **not the entire surrounding Git
checkout**; do not claim otherwise. The frozen 23-case manifest SHA-256 is
`3861f33b79c0b6d8f1c4a81ab382b7fe6f4ddbb9d865e3d96e5fdf0f0bb9bcc8`.

## Inspect and plan

```sh
mise exec -- bundle exec ruby bin/agru bench verify nl2repo --audited-scoring --offline --root .agru
```

**Expected exit status: 1.** Historical GR-01..08 remain blocked with null score.
The additive `audited_scoring` object identifies the selected scoped v2 path;
it is not a live readiness/preflight success. Do not remove the flag from actual
run/regrade commands: legacy grading remains a distinct, blocked path.

```sh
mise exec -- bundle exec ruby bin/agru bench plan experiments/nl2repo-audited-smoke.json --audited-scoring --offline --root .agru
```

Planning validates configuration, not image health or passing controls. The
template has fixed `experiment_id: nl2repo-audited-smoke`. Store experiment
insertion is insert-only: **use a fresh ID for every new run** in the same Store,
including a different repository/control. Regrade uses the existing ID instead.
No `protocol` key is needed in this manifest; the explicit CLI flag selects v2.

## Prepare persistent ordinary controls

The following creates only local control directories and verifies reference
bytes before copying. It refuses an existing destination rather than overwriting
operator work. Run once; retain these directories for inspection. The positive
control intentionally submits the trusted module; never expose this private
reference to an actual solver or ordinary candidate workspace.

```sh
mise exec -- bundle exec ruby -rfileutils -rdigest -e '
root = ".agru/m11c-operator-controls"
abort "control directory already exists; choose a fresh path" if File.exist?(root)
source = ".agru/nl2repo/reference/original-1d5699348d707e377aad7488da6a8a1b48a65933/retrying.py"
abort "reference module digest mismatch" unless Digest::SHA256.file(source).hexdigest == "d8f1cc7e269fe908cae965fb9338d3625c56c9e56a35435dcb6f78ee74a53e0a"
%w[reference empty incomplete].each { |name| FileUtils.mkdir_p(File.join(root, name)) }
FileUtils.cp(source, File.join(root, "reference/retrying.py"))
File.write(File.join(root, "incomplete/retrying.py"), "def retry(*args, **kwargs):\n    return lambda function: function\n")
'
```

Create fresh per-control manifests from the checked-in template. This prints
their paths/IDs and refuses overwriting existing manifest files:

```sh
mise exec -- bundle exec ruby -rjson -rsecurerandom -e '
base = JSON.parse(File.read("experiments/nl2repo-audited-smoke.json"))
%w[reference empty incomplete].each do |name|
  manifest = Marshal.load(Marshal.dump(base))
  manifest["experiment_id"] = "m11c-operator-#{name}-#{SecureRandom.hex(8)}"
  path = ".agru/m11c-operator-controls/#{name}.json"
  File.open(path, "wx") { |f| f.write(JSON.pretty_generate(manifest) + "\n") }
  puts "#{path}: #{manifest.fetch("experiment_id")}"
end
'
```

## Run, report, and regrade

These commands submit the persistent controls without invoking any model:

```sh
mise exec -- bundle exec ruby bin/agru bench run .agru/m11c-operator-controls/reference.json --repository .agru/m11c-operator-controls/reference --audited-scoring --offline --root .agru
mise exec -- bundle exec ruby bin/agru bench run .agru/m11c-operator-controls/empty.json --repository .agru/m11c-operator-controls/empty --audited-scoring --offline --root .agru
mise exec -- bundle exec ruby bin/agru bench run .agru/m11c-operator-controls/incomplete.json --repository .agru/m11c-operator-controls/incomplete --audited-scoring --offline --root .agru
```

Copy the incomplete manifest's `experiment_id` into `EXPERIMENT_ID`; get its
cell ID from the JSON report's `cells[0].id` and set `CELL_ID`:

```sh
EXPERIMENT_ID="COPY_INCOMPLETE_EXPERIMENT_ID_HERE"
mise exec -- bundle exec ruby bin/agru bench report "$EXPERIMENT_ID" --format json --offline --root .agru
CELL_ID="COPY_REPORTED_CELL_ID_HERE"
mise exec -- bundle exec ruby bin/agru bench regrade "$EXPERIMENT_ID" "$CELL_ID" --audited-scoring --offline --root .agru
mise exec -- bundle exec ruby bin/agru bench report "$EXPERIMENT_ID" --format json --offline --root .agru
mise exec -- bundle exec ruby bin/agru bench report "$EXPERIMENT_ID" --format csv --offline --root .agru
mise exec -- bundle exec ruby bin/agru bench report "$EXPERIMENT_ID" --format markdown --offline --root .agru
```

Regrade independently grades the **stored immutable submission**, not the
current control directory, appending an attempt without rerunning the solver.
Inspect attempt counts and unchanged submission identity. Reports need no
audited flag: they read persisted protocol/quality evidence. Retain all evidence;
do not rewrite historical results or reuse their experiment IDs.

Expected healthy local controls:

| Control | Score | Passed / expected | Executed calls | Quality basis |
| --- | --- | --- | --- | --- |
| Reference | 1.0 | 23 / 23 | 23 | `validated_quality_result` |
| Empty | 0.0 | 0 / 23 | 0 | `candidate_collection_failure` |
| Incomplete | 1 / 23 | 1 / 23 | 23 | `validated_quality_result` |
| Incomplete regrade | 1 / 23 | 1 / 23 | 23 | `validated_quality_result` |

Always verify actual persisted `protocol`, `quality_basis`, expected/collected/
executed counts, submission binding and grading attempts, not only the number.
Infrastructure/protocol failures, unhealthy reference, timeout and cancellation
are null scores, not ordinary zero-quality results. Do not combine distinct
quality bases into an undisclosed scientific aggregate.

## Existing automated acceptance

For the maintained transient-control acceptance, explicitly opt into local
grading (no downloads, no providers):

```sh
mise exec -- bundle exec ruby script/m11c_scoring_acceptance.rb --allow-local-grading
```

It creates fresh experiment IDs and transient reference/empty/incomplete control
repositories, executes the same four checks including independent regrade, then
persists reports and `.agru/m11c-acceptance/observations.json`. The latest
observations filename is overwritten by a subsequent acceptance invocation;
underlying Store experiments retain distinct IDs. Preserve a copy of any report
snapshot needed for comparison. The operator workflow above instead retains
control directories and manifests. Neither workflow establishes broad task
coverage, solver superiority, legacy-v1 validity, or adversarial collector trust.
