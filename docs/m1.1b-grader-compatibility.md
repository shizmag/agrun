## Suggested evidence labels (not implemented APIs)

1. **Static protocol audit**: source/metadata findings only. This document is here.
2. **Limited controlled native validation**: authorized cached assets, explicit
   grading opt-in, grader-only reference positive control and empty/broken negative
   control, immutable image/source identities, actual exit/log records. May report
   observed legacy counts/rates as diagnostic control measurements; must state
   residual-reference and stdout-authority limitations. It is legitimate to run
   these without claiming universal Docker security or adversarial resistance.
3. **Native-compatible trusted submission score**: controls above plus validated
   candidate-resistant collection, immutable submission binding, hidden asset
   confidentiality, import provenance and effective resource/network policy.
   Until proved, return blocked/untrusted with no authoritative score as required
   by `docs/m1.1-contracts.md:73-95`.
4. **Repaired protocol experiment**: explicit versioned changes such as shell
   semantics, corrected denominators, added pytest or a hardened collector.
   Report side-by-side against legacy native behavior on identical inputs. A
   useful repair is not automatically paper/official-compatible.

## Minimum control interpretation

* Reference pass: environment/test plumbing can execute this known implementation;
  does not prove solver validity or removal of residual reference modules.
* Empty candidate pass: investigate reference overlay/import leakage or scoring
  contamination; not evidence that an empty repository solves the task.
* Empty/broken candidate fail: useful negative control, but insufficient alone to
  prove no partial-reference fallback for other candidate shapes.
* Missing pytest, image/runtime failure, timeout, collection crash, no tests:
  preserve execution state and declared denominator; do not recast infrastructure
  failure as an authenticated semantic failure or omit it from coverage.
* Skip/xfail accounting: expose separately when a trusted collector supports it;
  retain fixed legacy denominator when describing legacy behavior.
* Forged pass text or mutable result files: cannot establish an authoritative score.
  Parser-only negative probes already demonstrate why native stdout is inadequate.
* Collection-count drift: preserve raw counts, declared total and capped legacy
  rate together. `98/96 -> 1` is a warning, not permission to silently change 96.

Normal tests must stay offline and Docker-free. Operational validation requires
explicit asset authorization and the existing allow-download path for any missing
assets; cached presence is not a license. No downloads or grader execution were
performed as part of this documentation-only audit.
