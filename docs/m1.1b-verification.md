## Remaining acceptance blocker and smallest next step

The primary deliverable is **not completed**: neither legacy compatibility nor
`nl2repo-audited-v1` has an authenticated native collection/result authority.
Pytest imports arbitrary submitted Python in its own process; candidate code can
alter collection, runner state or output. Copying tests separately, pinning image
bytes, disabling network and parsing JSON do not establish collector integrity.
The current clean path prevents accidental implementation overlay for this task,
but is not an adversarially verified isolation boundary and does not make tests
unreadable to arbitrary code in the evaluator process. Directory separation is
not a sandbox. This is a fundamental native-protocol isolation limitation under
the repository's existing contract, not lack of Docker or a positive reference.

Smallest next step: approve and independently validate a task-specific trust
model/collector execution boundary that can attest exact official collection,
execution and outcomes without candidate impersonation, or explicitly revise
the scientific contract to distinguish benign controlled observations from
adversarially authoritative scoring. Do not silently relax that contract or
label these diagnostic pass counts audited scores. General Python sandboxing
and a second benchmark implementation are outside this milestone's safe scope.

Original benchmark/dataset/container redistribution permissions remain unresolved;
Apache-2.0 upstream task-source permission does not license the benchmark corpus.
No population performance inference is supported by this one-task pilot.

## Bounded alternative assessment

FeatureBench is a possible follow-up, not implemented here. Its public README
(`https://github.com/LiberCoders/FeatureBench`, observed 2026-11-14, unpinned
metadata only) advertises an MIT license, Docker evaluation, gold-patch controls,
and a CPU-only 100-instance fast split. These are reasons to investigate, not
verified compatibility or permission findings. Feature-level patch completion
also measures a different construct from from-spec repository synthesis.
A future evaluation must pin source/data/images, inspect actual license terms
and collector/isolation semantics, and execute gold/negative controls first.
Changing benchmarks does not remove the existing evidence-integrity contract.
